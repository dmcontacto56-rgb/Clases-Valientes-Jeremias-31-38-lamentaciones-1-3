# Clase de Valientes · Jeremías 31–33; 36–39; Lamentaciones 1; 3

Sitio estático (HTML + CSS + JavaScript con módulos + JSON). Sin dependencias ni compilación.

Archivos en la raíz del repositorio:
`index.html`, `style.css`, `main.js`, `audio.js`, `effects.js`, `cursor.js`, `content.json`

Imágenes y sonido (mismos nombres que en `content.json` → `meta`):
`Nuevo-Simbolo-de-la-Iglesia.webp`, `gota-de-agua.mp3`, `jeremias por rembrandt.jpg`, `Agradar a Dios.jpeg`, `Jeremias en la cisterna.jpeg`, `Mapa compárativo.jpeg`

## Publicar
1. Sube todo a la raíz del repositorio.
2. Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
3. Abre la dirección de GitHub Pages (no funciona con doble clic en el archivo).
4. Tras cada cambio, recarga con Ctrl+Shift+R. Si falta o está viejo algún archivo, la página muestra un aviso amarillo.

Los textos, preguntas, regiones del mapa y recomendaciones se editan en `content.json`.
